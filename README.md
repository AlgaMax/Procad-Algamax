# ProCAD by AlgaMax

Professional Pattern CAD Software for Garment Industry

## Features

### Pattern Capture Module
- Camera-based pattern digitizing with automatic calibration
- Automatic notch, grain line, and grading point detection
- Multi-pattern batch capture
- Perspective correction and contour smoothing

### Pattern Making Module
- Complete editing tools (reshape, cut, join, split)
- Drawing tools (line, curve, bezier, polygon, freehand)
- Dart tools (create, move, open/close, transfer)
- Pleat tools (single, multi-pleats, ruffle/shirring)
- Seam allowance with variable widths
- Measurement tools (distance, angle)

### Grading System
- Size range management
- Grade point placement and rules
- Apply grading to patterns
- Stack tool for size comparison
- Export graded patterns

### Nesting Algorithm (Industry-Grade)
- **Average Efficiency: 76.69%**
- No-Fit Polygon (NFP) algorithm
- Genetic algorithm optimization
- 7 sorting strategies with best-of selection
- Support for 0°, 90°, 180°, 270° rotations
- Grain direction constraints
- Fabric defect avoidance
- Plaid/check pattern matching

### Marker Making Module
- Multi-size nesting
- Configurable fabric width
- Efficiency reporting
- Cost analysis

### Export Formats
- HPGL (.hpgl) - Plotter format
- PLT (.plt) - AutoCAD Plot format
- DXF (.dxf) - AutoCAD format
- SVG (.svg) - Vector graphics
- PDF (.pdf) - Print format

### Production Features
- Cost calculation (fabric, labor, overhead)
- Tech pack generation (Text, HTML, JSON)
- Marker reports

## Installation

```bash
# Install dependencies
npm install

# Development mode
npm run dev

# Build for production
npm run build

# Package for Windows
npm run package:win
```

## System Requirements

- Windows 10/11 (64-bit)
- 4GB RAM minimum
- 500MB disk space
- Camera for pattern capture (optional)
